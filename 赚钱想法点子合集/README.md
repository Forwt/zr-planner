# 赚钱想法点子合集

收集副业方向、游戏或产品点子、变现方式和待验证机会。零散一句话也可以入库，由助手整理；暂不要求立刻立项。

先用标签细分主题，例如：游戏、AI 工具、内容、获客、变现、待分类。需要独立分类文件夹时，先征求用户同意。

每个独立点子保存为一篇 `YYYY-MM-DD-简短标题.md`，同一想法的后续补充优先更新原记录。

## 条目格式

```markdown
# 点子标题

- 记录日期：YYYY-MM-DD（Asia/Shanghai）
- 标签：待分类
- 状态：待验证
- 来源：本次对话或原始链接；未知时注明未知

## 用户原话

保留原始表达。

## 整理摘要

用简短文字整理想做什么，和原话分开。

## 赚钱方式与目标用户

已有信息照实记录；助手提出的内容明确标为假设。

## 已知证据与待验证问题

缺少的信息写待补充，不编造结论或收入。

## 最小验证动作

仅记录建议或用户已确认的下一步；没有授权时不自动执行。

## 相关素材

链接到赚钱素材中的对应条目。

## 后续补充

按补充日期记录新的信息与变化。
```
