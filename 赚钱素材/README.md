# 赚钱素材

收集赚钱相关的案例、参考链接、截图、研究数据、文案、资源和可复用内容。保留来源，方便日后找到原始材料并关联具体点子。

先用标签细分主题和素材类型，例如：游戏、AI 工具、获客、变现、案例、数据、文案、待分类。新增分类文件夹或子文件夹前，先征求用户同意。

每份独立材料保存为一篇 `YYYY-MM-DD-简短标题.md`。已有相同来源或主题时，优先补充原记录。

## 条目格式

```markdown
# 素材标题

- 收录日期：YYYY-MM-DD（Asia/Shanghai）
- 标签：待分类
- 素材类型：案例、链接、截图、数据、文案或其他
- 来源链接或出处：未知时注明未知
- 作者与原始日期：有信息才填写，否则标为待补充

## 原始材料

保留用户提供的原文、链接或实际已保存的附件路径。

## 整理摘要

概括材料内容，不替代原文。

## 可借鉴之处

写明与赚钱方向的关系；推测明确标为假设。

## 关联点子或项目

使用相对链接关联现有记录；尚未关联则标为待补充。

## 核实情况与后续补充

区分已核实信息与待核实说法，按日期记录更新。
```
