# 赚钱想法与素材库

保存随手提出的赚钱想法、可参考的案例和可复用素材，方便之后检索、验证和推进。

| 资料库 | 放什么 |
| --- | --- |
| [赚钱想法点子合集](赚钱想法点子合集/README.md) | 副业方向、游戏和产品构思、变现方式、待验证的机会 |
| [赚钱素材](赚钱素材/README.md) | 案例、链接、截图、资料、数据、文案和可复用资源 |

之后把零散内容直接发给助手即可。助手负责提炼标题、按主题打标签、保存原话和来源，并关联已有记录。同一主题优先补充已有条目，避免重复。

两个资料库内先用标签细分主题。新增分类文件夹（包括子文件夹）前，助手需要说明名称、用途和必要性，取得用户明确同意后再创建。

具体归档约定见 [AGENTS.md](AGENTS.md)。
